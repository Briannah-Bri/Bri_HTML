# BRI_HOTSPOT Website

## Project Description
BRI_HOTSPOT is a local area network service provider offering fast and affordable internet packages to customers. This website serves as the online platform for users to learn about services, register accounts, and contact the company.

## Pages Included
- **index.html** - Home page showcasing internet packages and pricing
- **about.html** - Information about BRI_HOTSPOT services
- **contact.html** - Contact information and social media links
- **help.html** - FAQ page with common questions and answers
- **register.html** - User registration form
- **sign_up_form.html** - User login form

## Features
- Multiple internet package options (daily, weekly, monthly)
- User registration and login system
- Contact information with social media integration
- Help/FAQ section for customer support
- Responsive design for mobile and desktop devices
- Accessible navigation with ARIA labels
- SEO-optimized with meta descriptions

## Technologies Used
- HTML5 - Semantic markup
- CSS3 - Styling with responsive design
- Flexbox - Layout management
- Media queries - Mobile responsiveness

## Internet Packages
- Daily packages: 150MB, 300MB, 1GB, 2GB
- Weekly packages: 2GB, Unlimited
- Monthly packages: 30GB, Unlimited
- Special offers: 6-hour unlimited, Supersaver unlimited
